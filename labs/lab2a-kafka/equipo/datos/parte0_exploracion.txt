[8] Repetición del envío SIN key (Parte 0, paso 5 — "repite un par de veces")
--------------------------------------------------------------------------------
Cuatro mensajes más, cada uno en una INVOCACIÓN SEPARADA del console-producer
(es decir, cuatro sesiones de productor distintas):

$ for i in 1 2 3 4; do printf '{"nota":"ronda %s"}\n' "$i" \
    | docker exec -i st1630-lab2a-kafka kafka-console-producer \
        --topic pedidos-ventas --bootstrap-server localhost:9092; done

$ docker exec st1630-lab2a-kafka kafka-run-class kafka.tools.GetOffsetShell \
    --bootstrap-server localhost:9092 --topic pedidos-ventas

pedidos-ventas:1:1      <- +1
pedidos-ventas:2:2      <- +2
